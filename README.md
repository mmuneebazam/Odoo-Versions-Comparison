# Odoo Versions Comparison

## Odoo 15 → 20: Visual Comparison, Features, Performance & Upgrade Guide

An interactive, single-page visual comparison of **Odoo 15, Odoo 16, Odoo 17, Odoo 18, Odoo 19, and Odoo 20**.

This project was created to make Odoo version selection and upgrade planning easier for developers, technical consultants, ERP teams, and businesses.

Instead of comparing versions through scattered documentation, this project brings the major differences into one interactive dashboard covering:

- Release & support lifecycle
- Version-specific features
- Architecture changes
- Python & PostgreSQL requirements
- OWL/frontend evolution
- Native AI capabilities
- API capabilities
- Mobile & offline functionality
- Performance benchmarks
- Version scorecards
- Recommended use cases
- Upgrade paths

---

## 🚀 Project Overview

Odoo evolves significantly from one major version to another.

Choosing the right version is not only about using the newest release. Development teams also need to consider:

- Long-term support
- Module compatibility
- Community ecosystem maturity
- Performance
- Frontend architecture
- AI capabilities
- API capabilities
- Database requirements
- Migration complexity
- Custom module compatibility

This project provides a **visual decision-making tool** for comparing Odoo versions from **15 through 20**.

## ✨ Key Features

### 📅 1. Release & Support Timeline

A visual timeline showing the release and standard-support lifecycle of each major Odoo version.

| Version | Release | Standard Support |
|---|---|---|
| Odoo 15 | October 2021 | Ended October 2024 |
| Odoo 16 | October 2022 | Ended September 2025 |
| Odoo 17 | November 2023 | Ends September 2026 |
| Odoo 18 | October 2024 | Until September 2027 |
| Odoo 19 | September 2025 | Until September 2028 |
| Odoo 20 | September 2026 | Projected ~September 2029 |

> Support dates should always be verified against the latest official Odoo lifecycle information before making production upgrade decisions.
